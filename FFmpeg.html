🐍 Conversion HEIC via Python + pillow-heif CROSS-PLATFORM

L'équipe de libheif ne publie pas d'exécutables Windows (`.exe`) compilés dans ses releases officielles (ils ne mettent que les archives sources Linux/Unix).
La solution 100% fonctionnelle sur Windows, Mac et Linux : passer par la bibliothèque Python pillow-heif qui intègre déjà les binaires compilés de libheif et x265 pour Windows 64-bit.

⚙️ Installation à lancer une seule fois :

pip install pillow-heif

🧪 Test rapide sur un fichier :

python -c "import pillow_heif, sys; from PIL import Image; pillow_heif.register_heif_opener(); Image.open(sys.argv[1]).save(sys.argv[2], quality=80)" test.jpg test.heic
💡 Automatique : Le script détecte Python et pillow-heif. Si pillow-heif n'est pas installé, il tente l'installation automatique via pip install pillow-heif.

📋 Commande de conversion générée :

python -c "import pillow_heif, sys; from PIL import Image; pillow_heif.register_heif_opener(); Image.open(sys.argv[1]).save(sys.argv[2], quality=80)" "input.jpg" "output.heic"
